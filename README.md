# KiCad-Parts
KiCad Parts Library for Avionics' Standardised Components

clone this to your KiCad documents folder, and then rename the folder to your choosing. e.g. "UNSW_Rocketry_Parts". 

then, open KiCad, go to Preferences -> Manage Symbol Libraries -> Global Libraries, and with the folder icon, select the .kicad_sym file in this folder.

similarly, repeat for Preferences -> Manage Footprint Libraries -> Global Libraries, and add the .pretty file. 

now you have the UNSW Rocketry parts library installed into KiCad! you can start using our standardised components and share your boards with other people without loss of data. 3D models are also included here so everyone has the same 3D board preview.

all the best!
